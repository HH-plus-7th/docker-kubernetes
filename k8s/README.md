# 📁 k8s 폴더 안내

이 폴더에는 doku 앱(프론트 + 백엔드 + DB)을 쿠버네티스에 배포하기 위한 매니페스트 파일들이 난이도별로 준비돼 있어요.

본인 실력에 맞는 폴더를 선택해서 실습해보세요!

## 난이도 선택

| 폴더 | 난이도 | 설명 |
|------|------|------|
| `low/` | 🟢 쉬움 | 완성본 제공 - 읽고 이해한 뒤 배포해보기 |
| `medium/` | 🟡 보통 | 빈 칸 채우기 - 힌트를 보고 값 채워넣기 |
| `high/` | 🔴 어려움 | 뼈대만 제공 - 주석 읽고 처음부터 작성하기 |

## 배포할 앱 구조

```
[프론트 - nginx]
      ↕ /api 요청 프록시
[백엔드 - Node.js Express]
      ↕
[DB - PostgreSQL]
      ↕
[PVC - 데이터 영구 저장]
```

## 사용 이미지

| 서비스 | 이미지 |
|------|------|
| 프론트 | `96grappe/doku-front:v1` |
| 백엔드 | `96grappe/doku-backend:v1` |
| DB | `postgres:15` |
